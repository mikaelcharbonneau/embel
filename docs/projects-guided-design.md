# Projects

The user approved implementing the former Brands collection as Projects from [Fluid — Screens, page 3:2](https://www.figma.com/design/HP219GuYbpE8F1wHxj0h6N/Fluid-%E2%80%94-Screens?node-id=3-2) on 2026-10-10. Frames 5:2 and 6:54 define the populated and empty states. This design record does not authorize preview publication, provider spending, migrations or public access changes.

The collection now uses the approved 80px rail, 76px toolbar, 1008px workbench, three 324×264px cards per desktop row, search, Filter and Sort controls, and the first-project empty state. Mobile has a single column and the existing navigation dialog. Thirty-one original SVG exports preserve the native geometry and bytes for both shell variants, grids and actions. Reference project names and descriptions appear only in explicitly synthetic browser fixtures.

Navigation and collection return links say Projects. `/brands`, browser draft links and `/brands/account/:id` remain compatible. New project and Create a brand draft open the existing scope-aware creation flow; its Create a logo link preserves access to the separate logo workflow.

Browser drafts and account copies share a searchable grid while retaining separate storage, destinations and ownership. Scope and storage filters and alphabetical/creation/recent ordering affect presentation only. Account pages keep the original server cursor, microsecond ordering, bounded request timeout, validated continuation merging and retry behavior. Owner/generation changes unmount private listing state immediately; search/filter/sort state remains outside that boundary. Already-loaded account rows survive a later-page failure. Search explicitly covers only loaded account titles and browser titles/briefs; pagination remains available when filtering returns no matches.

The account summary API exposes scope, title, creation date and revision, but no brief, stage or update timestamp. Account cards therefore label stage Unavailable, describe the brief as available when opened, show Created dates and use creation dates for recent sorting. Browser stages and Updated dates come from the saved draft. Typographic previews display project labels, not generated or approved logo assets. No account summary is enriched through hidden per-card writes or provider calls.

The Filter icon has an intentional 16px Figma layout slot with an unscaled, unclipped 20px SVG child; its wrapper preserves that structure and the original SVG root dimensions. Unavailable account verification and unreadable browser storage show their recovery notices and never claim the collection is empty.

Verification uses read-only synthetic account API responses and valid browser drafts against a local production build. It covers reference geometry, native artwork, desktop/mobile layouts, empty and creation states, filters, sorting, immutable device storage, pagination anchors, retained rows after failures, and immediate account masking. This is separate from live database or provider acceptance. Non-secret artwork, browser, source and deployment receipts belong outside the checkout at `/workspace/scratch/fluid-projects-figma-20261010/`.

The full project workspace continuation is documented in [Project workspace screens](project-workspace-design.md). It covers the fourteen current artboards on pages 3:16–3:29; the collection remains compatible with its existing browser/account routes.
