# Assets visual library

Approved source: [Fluid — Screens, Assets](https://www.figma.com/design/HP219GuYbpE8F1wHxj0h6N/Fluid-%E2%80%94-Screens?node-id=3-3), frame 6:8398. Native reference: 1440 × 900, 80 px sidebar, 76 px toolbar, 1008 px content, three 324 × 216 px cards with 18 px gaps and 130 px previews.

The screen reuses the owned account library, server-backed project/format filters, stable pagination, revision-fenced likes/saves, immutable version restoration and verified private previews/downloads. Search matches kind, project title and displayed format within loaded rows. When a cursor remains, the search discloses that limit and keeps Load more available even with no current matches. It never claims a server-wide search.

Original grid and 13 icons are unmodified native SVG exports in public/assets-library. Sample brand artwork is account-supplied content: no design examples are seeded, no unsupported SVG/JSON preview is fabricated, and metadata-only/missing/unverified files retain honest states. Account labels remain generic because the session does not provide a display name.

Collection vocabulary now says Projects. Likes/saves and additional version metadata remain accessible in each card's Actions menu, revealed on hover, keyboard focus and touch devices. Details remain available from both the preview and original chevron. Tabs retain active filters during keyboard navigation. Action menus are exclusive and Escape also dismisses them after a retention write temporarily disables the focused control. Narrow screens use one column.

No provider activation, new storage ingestion, migration, credential change or public release is included. Verification uses dedicated headless browsers and synthetic account/file replies; it does not establish live account/provider acceptance.
