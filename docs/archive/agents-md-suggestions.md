1. **Add the engine to "Agreed app behavior".** State that all AI runs on the generation engine
   (Vercel Workflow inside the web app, `docs/generation-engine.md`), and that the old worker, daemon,
   API-text worker and ChatGPT-plan mode no longer exist.
2. **Rewrite the "durable background jobs" line in "Reliability and protection".** Say the engine

   systems; AI work goes through the engine.
