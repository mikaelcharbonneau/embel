# Reviewed visual direction

This local implementation connects saved Inspiration choices to the existing post-logo identity pipeline. It keeps the older `/identity` reference/system contract intact and does not enable its unavailable `identity.image` operation.

Inspiration links to **Review visual direction** on `/brands/account/:projectId/logo/directions`. The same review can be opened in the logo workspace before logo approval. It displays the exact saved overall/element likes and attributed catalog descriptions. The user can write character, color, typography and graphic guidance, then explicitly review and save it. There is no generated interpretation on read. Guidance affects the palettes, typography and graphics proposed by `identity.logo_directions`; initial logo concepts still use their existing saved logo brief and owned reference inputs.

The editor restores actual saved guidance, retains unsaved words in account-fenced tab memory, participates in sign-out/unload protection, and never stores private drafts in localStorage. A failed or interrupted save requires a fresh read. A lost successful reply can be confirmed without another write. When project details, saved likes or another reviewed version change, the user compares the latest saved words and explicitly keeps theirs or loads the saved guidance before saving again. Earlier review versions remain immutable; reusing their words creates a draft for a new explicit review against current references. The UI shows the latest 20 earlier reviews; older rows are retained.

`20261013140801_reviewed_visual_direction.sql` depends on the Inspiration migration. It adds `project_visual_directions` with forced owner RLS, authenticated read-only access, immutable rows and two narrow authenticated RPCs. Saves derive ownership from verified authentication, build reference descriptors from the private immutable catalog, and check project, selection and review revisions under the existing project lock. Caller-supplied artwork, ownership, authorization and source metadata are rejected. Reading does not create a row, and existing projects without Inspiration choices or a review retain their previous generation path.

The existing quote source constructor adds an optional exact reviewed snapshot. The existing job admission transaction rechecks all direction sources, including guidance and font records, before freezing the input. A changed source rolls back the job, request and reservation and requires a new quote. The client also rechecks guidance before quote confirmation. Queued/running requests retain their original frozen input; when a later change makes that input stale, completed results are retained without moving the current direction head. Current saved directions and dependent deliverables are reported as needing review, and stale components cannot be newly approved. Existing idempotent jobs, cancellation, cost/usage acceptance and separate identity selection/approval remain in force.

The text provider receives exact approved logo geometry, actual permitted font versions, existing reference metadata and the reviewed text/aspects. Catalog images are never copied into privately owned media or described as generated output, and attribution is never treated as a license. The adapter makes no additional image, discovery or font request. The current generator still needs its separately configured worker/provider and owned permitted fonts. Saving visual guidance alone neither enables that runtime nor approves an identity, and exports remain outside this increment.

The lead applied and verified the migration on 2026-10-13 as part of the [authorized database rollout](database-rollout-20261013.md). Its installation did not activate a worker or provider. Local tests and browser evidence are recorded separately in `/workspace/scratch/fluid-integration-20261013/identity`.
