# Trademarks design and behavior

The user selected Fluid — Screens, page `3:11`, on 2026-10-10. Search frame `7:8422` (1440 × 900) and Fill frame `40:2705` (1440 × 941) are the approved references. The implementation uses native Geist/neutral/magenta styling, original exported SVG artwork and the shared collapsed/expanded/mobile shell. Figma's sample names, goods and personal identity are not seeded into the application.

Search opens first. Name, requested territories and goods/services are controlled draft fields shared with Fill. Include similar names is a temporary query preference; it does not establish registry support. The manual-tools increment adds explicit browser-name import and a manual search brief with official WIPO/USPTO links. It dispatches no provider request. Query edits clear the prior brief. No matching records, clearance, registrability, filing or registration are fabricated. See [standalone manual tools](standalone-manual-tools.md).

Fill preserves all six existing intake sections and their exact review binding. Primary name/offering and owner fields match the reference arrangement. Additional mark representation, owner contact, classification, document plan and unsourced notes remain under Additional dossier details. Territories remain free text because no supported-coverage catalogue is approved. The summary reports all six input sections, rather than claiming the reference's three-section summary proves completeness. Review and actual JSON draft-preview export remain available for incomplete drafts, with their existing limitations. Export is not an official filing dossier.

Search, Fill, Library and History use keyboard-operable tabs. Library exposes the current working draft only; the account contract stores one draft, not multiple trademark records. History shows the latest verified save revision/time when present and explains that older revision history and registry searches are unavailable. Unsaved edits remain distinguished from the saved receipt. No history or persistence is invented for the tab-only manual fallback.

Account saving, import replacement confirmation, revision conflict and uncertain-save recovery, explicit reload confirmation and saved-source promotion retain their existing host contracts. Recovery controls remain outside disabled editor fields. The editor remounts on owner/verification generation and successful reload; transient search/tab state cannot carry private input into another account. Manual mode receives empty defaults and stores no owner information in browser storage. Promotion retains known context without copying owner contact data or legal conclusions.

Verification uses dedicated headless desktop/mobile browsers and synthetic account/provider replies only. Original SVG exports, hashes, screenshots, check results and deployment receipts are retained outside the checkout at `/workspace/scratch/fluid-trademarks-figma-20261010/`. These do not establish live registry research, database acceptance or hosted authenticated editing.

This design record does not authorize a new preview release or changes to deployment protection. No migration, new credentials, paid provider call, registry activation or public release is included.
