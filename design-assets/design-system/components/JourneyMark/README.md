# Journey mark

The four steps of one brand (Strategy, Voice, Identity, Assets) at card size. You provide the state of each step and the sentence that goes with it.

- Four short bars in journey order. **Complete** is filled ink; **current** is a 2 px ink outline; **not reached** is a 1 px `color-border-control` outline. The three differ in shape, not in colour alone.
- It never stands alone: the stage is always written beside it ("Identity · 6 concepts to choose from"). The mark itself carries `role="img"` and a label such as "Step 3 of 4".
- Used on the project card. The project bar keeps its own, larger steps.
- No hover, focus or pressed state: it is not a control.
