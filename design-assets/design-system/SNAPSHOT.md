# Embel Design System: snapshot

A read-only copy of the published Embel Design System
(https://claude.ai/artifact/NrcVPniQFUPdtrBBtY9V8J), taken on November 14, 2026 from version
1794614133-df61, so sessions that cannot open claude.ai can read it.

- `README.md`: the system's rules (voice, colour, type, space, layout, motion, states, icons).
- `components/<Name>/README.md`: one page per component and pattern.
- `components/bundle.css`: every component class (`e-…`) and the icon masks. The icon names it
  defines are the design system's Lucide set.
- `tokens.json` (every value) and `tokens.css` (the same tokens as CSS variables).
- `changelog.md` and `contrast.md`.

The published system is the source of truth. If it changes, refresh this copy before relying on it.
